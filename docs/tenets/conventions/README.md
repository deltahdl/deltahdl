# Convention Tenets

These are the non-negotiable rules for the documents that state how work
is done, and for whatever an assistant retains alongside them. A tenet is
true whatever this repository holds: it names no language, no tool, no
directory and no count. Where a tenet and the repository disagree, the
repository is what changes.

## A Convention States a Rule, Not a State

Write what must always be true, never what happens to be true now.

A convention is read as instruction and acted on without checking,
because checking it is the work it exists to save. So a sentence
describing the current shape of the work — a threshold, an inventory, a
count, the name of a part, the size of a file, what some mechanism
happens to enforce today — is believed long after the work has moved.
The work changes and the sentence does not, and nothing announces the
moment they part. From then on the document is not merely out of date; it
is confidently wrong in the one place a reader is least likely to look,
having been written precisely so that nobody would.

Where a mechanism already decides a question, the convention names the
authority and stops. Naming it survives every change to the value; the
value does not. What is left after the state is removed is the part worth
reading: which authority governs, what to do when it objects, and what a
reader is expected to have decided before writing anything at all.

The test is whether the sentence would have to be edited by someone
changing the work it describes. If it would, it is a description, and it
belongs where the change is made.

## A Rule Has One Home

One rule, written in one place, with every other place pointing at it.

A rule copied is not a rule reinforced. It is a second rule that has not
been told about the first, and it stays agreeable for exactly as long as
nobody edits either one. The edit then lands on whichever copy the author
had open, and the copies disagree from that moment with nothing to signal
it. Both are still read, and a reader has no way to tell which one the
author meant.

This binds hardest on copies kept where they cannot be reviewed — a
private store, an assistant's retained notes, anything that travels with
one person or one machine rather than with the work. Such a copy is
invisible to everyone who would otherwise catch the divergence, and it
outlives the version that was corrected. Keep in that store only what is
true of that store alone.

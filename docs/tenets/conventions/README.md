# Convention Tenets

These are the non-negotiable rules for the documents that state how work is done, and for whatever an assistant retains alongside them. A tenet is true whatever this repository holds: it names no language, no tool, no directory and no count. Where a tenet and the repository disagree, the repository is what changes.

## A Convention States a Rule, Not a State

Write what must always be true. Never write what happens to be true now.

A convention is read as an instruction and acted on without checking, because checking it is the work it exists to save. A sentence describing the current shape of the work is therefore believed long after the work has moved. Such a sentence gives a threshold, an inventory, a count, the name of a part, the size of a file, or what some mechanism happens to enforce today. The work changes and the sentence does not, and nothing announces the moment they part. From then on the document is worse than out of date. It is confidently wrong in the one place a reader is least likely to check, because it was written precisely so that nobody would have to.

Where a mechanism already decides a question, name the mechanism and stop. The name survives every change to the value; the value does not. What is left once the description is removed is the part worth reading: which authority governs, what to do when it objects, and what a reader is expected to have decided before writing anything at all.

To tell a rule from a description, ask whether someone changing the work would have to edit the sentence. If they would, it is a description, and it belongs where the change is made.

## A Rule Has One Home

Write each rule in one place, and point at that place from everywhere else.

A rule copied is not a rule reinforced. It is a second rule that has not been told about the first, and the two agree for exactly as long as nobody edits either one. The next edit lands on whichever copy its author had open, and from that moment the copies disagree with nothing to signal it. Both are still read, and a reader has no way to tell which one the author meant.

This binds hardest on a copy kept where it cannot be reviewed: a private store, an assistant's retained notes, anything that travels with one person or one machine rather than with the work. Nobody who would otherwise catch the divergence can see such a copy, and it outlives the version that was corrected. Keep in that store only what is true of that store alone.

## The Rule Comes Before Its Reasons

Say what to do first. Give the reasons for it afterwards.

A reader opens a convention to find out what is required of them. Reasoning placed first makes them carry an argument they cannot yet use, and the requirement arrives only once they have read to the end of it. Every reader pays that cost, and pays it every time.

Give each sentence one instruction. A sentence carrying two lets a reader who acts on the first walk away without noticing that a second was there.

## Plain Words Carry the Rule

Write the rule in ordinary words. A figure of speech may follow the rule and must never stand in for it.

An image is memorable once it is understood and opaque before that. A reader who meets the image alone has to guess the rule back out of it, which is slow and sometimes wrong. Write the rule, then keep the image after it wherever it genuinely helps a reader remember.

Name the thing itself rather than the category it belongs to. A category word stands for many things, so a reader given the category has to work out which member was meant. Define a term the first time it appears, or use the ordinary word in place of the term.

Use a list to enumerate things, and a table where a table genuinely reads better than a paragraph. An argument is prose. Splitting one into bullets hides which step rests on which, and claims that the pieces are alike and countable when they are neither.

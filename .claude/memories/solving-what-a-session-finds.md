# Solving what a session finds

File what you find as an issue, then solve it rather than moving on.

**Why:** This is reminder :08 of `.claude/skills/autopilot/SKILL.md`, and the notes have to say what the reminder says or a session runs under two rules. The issue makes the finding durable, since the task list and the scratchpad are not ([[research-lives-in-issues]]); solving it in the same session spends the reading that found it while it is still in hand, rather than leaving a later session to redo it.

**How to apply:** File the finding as its own issue when it arises, unless the commit in hand fixes it or an open issue already covers it ([[what-does-not-get-filed]]). Finish the work in hand, then solve the issue in the same session, in a push of its own where the rules on grouping require one, closing it with `Closes #N`. A finding that cannot be solved without a person's decision is labelled 'needs decision' instead.

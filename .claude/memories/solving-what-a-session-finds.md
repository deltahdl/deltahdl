# Solving what a session finds

File what you find as an issue. Solve it now only if the work in hand cannot move forward without it; otherwise move on.

**Why:** This is reminder :08 of `.claude/skills/autopilot/SKILL.md`, and the notes have to say what the reminder says or a session runs under two rules. The issue makes the finding durable, since the task list and the scratchpad are not ([[research-lives-in-issues]]). Solving every finding on the spot would pull the session off the work in hand for each one, and a filed issue is picked up by the issue loop in its turn.

**How to apply:** File the finding as its own issue when it arises, unless the commit in hand fixes it or an open issue already covers it ([[what-does-not-get-filed]]). If the work in hand is blocked on it, solve it first, in a push of its own where the grouping rules require one. Otherwise carry on with the work in hand and leave the issue to the loop.

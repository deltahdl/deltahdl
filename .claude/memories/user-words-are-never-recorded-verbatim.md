# The user's words are restated, never copied

Nothing the user writes is recorded verbatim, anywhere. A memory, an issue
title or body, a commit message, a comment in code, a task subject, a feedback
draft and a session summary all carry the user's point in fresh words, with no
quotation marks around the user's own sentences and no unquoted copy of them
either.

**Why:** The user does not want their own wording kept on record. A paraphrase
carries the rule just as well, and the notes, issues and history stay free of
it.

**How to apply:** Before writing down a correction or an instruction, restate
it as the rule it sets, in the note's own terms. A tool or template that asks
for the user's words quoted, such as a feedback draft's field for what the user
said, gets a paraphrase marked as one. A user's message that names a term,
file, label or command keeps that one name, which is not a quotation of the
sentence around it. The same holds for the standard's sentences, per
[[lrm-text-is-copyrighted]], and for what [[recording-what-a-session-learns]]
says a memory holds.
